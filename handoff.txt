Install:

3. Copy the included assets into your existing assets folder.
4. Keep your existing lion-logo.png and studio-concept.png.
5. Run:
   git add .
   git commit -m "Replace Ms Ryanne with Judah and Noa"
   git push origin main

If Cloudflare is connected to your GitHub repo/branch, the push should trigger deployment automatically.
